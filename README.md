<summary><b>本次更新 · v1.11.7（点开看变化）</b></summary>

**① 新增「🎯 匹配素材并引用」——参考旧包算法，把引用标记真的写进正文**

老包（`ComfyUI_MRBoard/director/studio_routes.py`）的「匹配引用」才是用户熟悉的那套：
它读素材文件名当关键词，命中就在正文里**插入 `<Picture N>` / `<Audio N>` / `<Video N>`**。
本节点以前只有「按收藏库名字匹配、只算命中不改文本」，所以"匹配了却没引用"。

新端点 `POST /mrnext/studio/asset_match` 完整对齐老包语义：
- **关键词 = 文件名去扩展名 + 去常见修饰后缀**（`配音 / 三视图 / 角色卡 / 场景概念图 / 概念图 / 场景图 / 场景`）
- 支持「N=文件名」**引用表**（`1=云妙衣.png`，无序号行从 1 自动编号），编号直接成为 `<Picture N>` 的 N
- 命中后**在关键词之后插入标记**（老包 `pos + len(keyword)` 同款），返回可直接写回 `shots[i].text` 的正文
- 跳过正文里已存在的同类标签、遵守官方上限 **图片 9 / 音频 3 / 视频 3**
- 返回 `unmatched`（带原因：关键词为空 / 文件不存在 / 未找到匹配），前端提示里直接显示

候选来源优先级：**引用表 → 收藏库 → 素材库索引**（素材库兜底只对图片生效 ——
否则「云妙衣配音.wav」会把角色名当关键词，在 `<Picture 1>` 旁边粘一个 `<Audio 1>`）。

**② 音频参考插到「它配的那句台词」上，而不是名字旁边**

老包只把 `<Audio N>` 插在关键词后，那在 H3 里是**悬空标记**（模型不知道给谁配音）。
现在音频改插成：

```
云妙衣 <Picture 1>： 音色参考 <Audio 1>：你终于来了。
陆沉 <Picture 3>： 音色参考 <Audio 2>：我来了。
```

这个形态正好命中 `h3prompt.py` 的 `RE_VOICE_REF_MID` → 组装成
`(S1) says (voice reference <Audio 1>): [Chinese] 你终于来了。`
已做**离线 round-trip 断言**（`t_match_voice.py`，6 项）：插入 → 抽出台词 → 音色编号正确、画面无残留标记。
同一句台词只绑一个音色（两条音频不会叠在一处）；正文没有任何台词行时不插音频。

**③ 修掉一个真 bug：`str.isalnum()` 把中文当字母 → 中文名匹配不上**

匹配边界原来写的是 `text[st-1].isalnum()`，但**中文汉字的 `isalnum()` 也是 True** →
「在废弃仓库门口」里的「在」被判成"字母" → 只有句首那一个名字能命中。
改用 ASCII 判定（`_ASCII_ALNUM_RE`）。同一处坑在 `_scan_per_shot_refs` 的角色名匹配里
也存在，一并修掉（这也是"拆分后引用素材没全带过来"的残留原因之一）。

**④ 按钮分工**

- **🎯 匹配素材并引用**：旧包同款，插入标记 + 写回正文 + 同步 `refMap`（主力）
- **🔍 语义匹配**：保留旧的「按收藏名算命中、不改文本」，适合正文里已经写了角色名的场景

**校验（真机 + 离线）**：新增 `asset_match_e2e` **30 项**、`t_match` **38 项**、`t_match_voice` **6 项**。

**仍未接入（如实列出）**：`v2v / rv2v / mixed` 三种 task_type、`sigmas` 外接噪声表。

**① 参考不生效的真凶找到了：r2v 用错权重（fl2va ≠ ref2va）**

官方两份模板用的 UNET **不是同一个**：

| 官方模板 | UNET |
|---|---|
| `minimax_h3_director_r2v.json`（参考生视频） | `minimax_h3_ref2va_pruned_int8_convrot.safetensors` |
| `minimax_h3_director_fl2v.json`（首尾帧） | `minimax_h3_fl2va_pruned_int8_convrot.safetensors` |

而本节点原来的默认权重挑选顺序是 `fl2va → ref2va`，**r2v 永远拿到 fl2va**。
fl2va 是「首尾帧」微调，没有被训练过参考条件 → `ref_images` / `ref_videos` / `ref_audios`
会被当噪声**忽略**。这解释了一个反复出现的现象：构图里参考全都连上了、提示词也标了，
出片却完全不参考 —— **因为权重根本不是参考任务的那份**。

现在：
- 后端按模式给推荐权重（`unetsByMode`：r2v → ref2va，其余 → fl2va）
- 模型页新增「**跟随模式自动选权重（推荐）**」：切换模式自动换权重（升级前的旧配置会被自动纠正）
- r2v + 非 ref2va 权重时，模型页给**红色告警**并附「🔧 切到 ref2va」一键修复；出片时也会提示
- 手动选过权重即关闭自动跟随（不覆盖用户选择）

**② 新增「🌐 公共提示词」（对齐官方导演台 common prompt）**

- 导演台参数区新增一页：一段文字 + 「并入每个分镜（官方 `commonEnabled`）」开关 + 合并预览
- 合并规则与官方 `concat_common_segment_prompt` 完全一致：**公共提示词 + 空行 + 本镜提示词**
- 落地方式也照官方：r2v/i2v/fl2v 写进官方 `timeline_data.global.prompt` + `commonEnabled=true`，
  由官方引擎逐镜拼接；t2v 单节点没有 group，由本节点按同一规则拼接
- **公共提示词为空时绝不打开 commonEnabled** —— 否则官方会把「本镜提示词」拼两遍
- 「出片选中」与一键流水线都会带上它（同一个参数源）

<summary><b>v1.11.2（点开看变化）</b></summary>

**修「音色参考一直不被参考」—— 两个真因，都在官方对齐上**

上一版已经把 `<Audio N>` 接到了官方的 `ref_audios.ref_audio_{N-1}` 槽，干跑构图里也确实有连线。
但**连线对 ≠ 音色生效**：真正吃音色的是提示词，而提示词侧有两个错位。

**① 音色标记与它要配的那句台词被切开了（主因）**
- 模板写法是 `…嘴巴在动，音色参考 <Audio 1>：<d>[Chinese] 台词</d>`
- 旧组装把 `<d>台词</d>` 抽成独立的 `(S1) says: …` 行，`<Audio 1>` 却留在画面描述里
  → 送进模型的文本变成：画面段末尾一句**悬空的「音色参考 <Audio 1>：」**（后面什么都没有）
  + 另一行不带任何标记的台词 → **参考音频与"这句用哪个音色"的绑定彻底丢失**
- 现在：`<Audio N>` 被**搬进它配的那句台词行**，写成
  `(S1) says (voice reference <Audio 1>): [Chinese] 台词`，画面里的空壳一并清掉
- 三种模板写法都认：`音色参考 <Audio 1>：`（紧贴）、`音色参考 <Audio 1>，嘴巴零动作：`（逗号分隔）、
  裸 `<Audio 1>：`（省略关键词）。**非配音用途**的音频参考（如 `环境音参考 <Audio 3> 是风声`）**不会**被误搬

**② 官方参考槽编号是「按非空槽的先后顺序」，跳号就会错位（第二个真因）**
- 官方 `MiniMaxH3ReferenceToVideo.execute` 里是 `for img in (ref_images or {}).values()`
  —— 走**插入顺序**，**空槽不占号**。所以官方 UI 里槽位永远连续
- 我们的九宫格/音频格可以跳号（只填第 2 格）。这时官方把「第 2 格」当作 **`<Audio 1>`**，
  而提示词里写的还是 `<Audio 2>` → **标签指向不存在的参考 = 音色没给上**
- 现在：`<Audio N>`/`<Picture N>` **按编号升序压成连续槽位**，并把提示词里的标记**同步重编号**
  （`<Audio 2>` 单独出现 → 槽 `ref_audio_0` + 提示词改写为 `<Audio 1>`），
  恢复「提示词第 k 号 ↔ 第 k 个非空槽」这个官方不变量；编号本就连续时行为完全不变

- 顺带修一个老 bug：**风格行里只要出现「色调」两字就会被从中间截断**（「明亮暖色调，柔光滤镜…」→ 只剩「，柔光滤镜…」）；现在关键词必须"行首 + 冒号"才算键值对
- 「📄 剧本模板」里新增 **⏱ 时间码分镜模板**，点「使用」即可套用
- 校验：离线单测 19 项 + 真浏览器 e2e 25 项（含真点「拆分分镜」按钮后的 6 镜 / 时长 / 公共前缀 / 分镜卡，以及前端解析器抽出的 2 角色 + 完整风格）

**⑧ 修「时间线『全部导出』按钮有时候不显示，点一下才出来」+「剪辑面板轨道素材一多就被裁切」（本版）**
- **导出方式按钮（🎬 全部导出 / 📦 分段导出）首屏就是空的**：它创建时不带文案、只在"被点击"时才写入 → 第一次进「🎬 时间线」看到的是一个 **126px 宽但只有 11px 高的空条**（视觉上就是"按钮没显示"），**点一下才冒出文字**。现在构造后立刻刷新 + 每次渲染都同步（从旧计划/存档恢复 `exportMode` 也会跟着变）
- 同一行的 **「（仅一采）」提示原来是写死的**，把「二采」下拉切成「自动二采」它也不变 → 现在随下拉实时刷新
- **剪辑面板：素材一多，末尾片段被顶出轨道可视区（看着像被裁切）+ 标尺不跟滚动**：以前时间轴比例固定 `30px/s`，片段一多轨道就横向溢出。现在**按"整条时长 ÷ 轨道可视宽度"自动缩放**，素材越多比例越小、整条全览；按钮行右侧会提示 **「已自适应缩放 x px/s，整条 xxs 全览」**。多到实在看不清时（平均片段 < 20px）才停止缩小、保留横向滚动，并让**标尺与三条轨一起滚**（刻度始终对得上片段）
- 顺带修一个藏了很久的换算 bug：节点 DOM 面板会被画布**整体缩放**（实测 0.9），而指针事件给的是"屏幕像素"、面板内部用的是"布局像素" → 播放头点选与裁剪拖拽一直缺这个系数（缩放 90% 时"拖 60px 只走 54px"）。现在统一补偿，裁剪真正跟手
- 校验：真浏览器 e2e **21 项**全绿（含"10 个片段零横向溢出、片段全部在轨道内""播放头精确落在点击处 ±3px""拖 -60 屏幕像素 → 宽度减少 60px"）

**⑨ 修「自动拆分到导演台后，引用素材没全部落到下方格子」（本版）**
三个根因一起修（用户实报：提示词里 4 个素材标记，格子只有 1 张）：
- **`<Picture N>` 等显性标记只有"手动绑定过"才注入** → 现在没绑定时**按素材库序号回退**（与提示词里 token 的显示完全一致），提示词里看得见的标记，格子里就有图
- **中文名后面紧跟中文就匹配不上**（`小白兔跳过来` 里的 `小白兔` 因右侧是汉字被判掉）→ 改成"左边不是字母数字 + 不落在更长的已知名字里"（`张三` 不会误吃 `张三丰`）
- **后端只认前端传来的名字→文件映射** → 现在前端没给/给过期时后端自己解析（收藏库同名条目 → 素材库文件名主名），API 自洽
- 附带修：**单镜剧本拆不出来**（只有 1 块时被当成"定义头"吃掉 → 报"未切出分镜"）；现在带时长的单块一律当分镜
- 前端再加一层保险：时间线建立每镜缓存时，按正文里能看见的标记/名字**补齐**素材槽（幂等，只加不删，手动挑过的不会被覆盖；已有的分镜不用重新拆也能补上）
- 校验：离线 6 项 + 真浏览器 e2e 12 项（含三张素材全带过来、第2镜 refMap 为空也能按正文补出）

**⑩ 首尾帧生视频：素材区只有「首帧 / 尾帧」两个框（对齐旧包 · v1.10.1）**
- 切到 **FL2V（首尾帧生视频）** 时，时间线下方素材区**只给两个上传框**：左「首帧」（绿角标，必填）、右「尾帧」（橙角标）——就是本模式全部的参考图；**不再有九宫格，也没有视频/音频小格**
- **I2V** → 只给「首帧」一个框；**L2V（尾帧生视频）** → 只给「尾帧」一个框；**R2V** 仍是九宫格 + 音视小格；**T2V** 无素材区
- 两个框支持：点击上传 / 「从素材库选图」下拉 / 右上角 × 清除；框体宽高比跟随当前出片分辨率（竖屏就是竖框）
- **槽位语义严格保序**：只填尾帧时，尾帧就待在「尾帧」格，不会被挤到「首帧」格（老实现会把空槽压掉 → 三种模式跟着串）
- **少填一张也能出片**：FL2V 只填首帧 → 自动按 I2V 出片；只填尾帧 → 自动按 L2V 出片（回执里说明）。缺对应帧时前后端都会拦住并提示，不会白等一轮
- 校验：离线单测 8 项 + 真浏览器 e2e 17 项全绿（含"删掉首帧后尾帧不位移""i2v 只剩尾帧被拦住"）

**⑪ 外部模型节点 / 第三方加速节点接口（外接后内置加速自动失效）**
- 「🎬 时间线」→「⚡ 加速」页新增 **外部节点（模型 / 加速）** 区块：点「🔗 扫描画布外部节点」读当前画布
  - **外部模型节点**：UNETLoader / CheckpointLoader / GGUF / Nunchaku / CLIPLoader / VAELoader / LoraLoader …… 列出文件名 + 一键 **「采用」**（填进本节点「🧠 模型」页）；文件名不含 `minimax/h3` 会标 ⚠ 并二次确认（防止误用 SDXL 之类模型）
  - **第三方加速节点**：SageAttention/BlockSparse、TeaCache/缓存类、torch.compile、FlashAttention、Nunchaku/torchao 量化、分块显存优化……
- **画布上一旦出现第三方加速节点 → 内置加速自动整体失效**（BlockSparse 归位「关闭」、TE-Speed 归位「关」、蒸馏 LoRA 归位「(无)」）。原因：两者都会改写模型与噪声调度，叠加 = 双重加速（画面发灰、显存反而爆）
- 出片回执会写明 `🔗 已检测到外部加速节点（…）→ 本节点内置加速已自动失效（原本启用：…）`，让你知道内置加速为什么没生效
- 确实想叠加 → 勾 **「强制启用内置加速（忽略外部节点）」**，界面提示"可能重复叠加"
- **后端双保险**：即使前端没传，构图阶段同样让路 —— 送进队列的图绝不会同时出现内置与外部加速
- 校验：离线单测 **21 项** + 真浏览器 e2e **19 项**全绿

**⑫ 资产保存路径 + 右键导出（自动分类）+ 本地删除实时检测（v1.9.9）**
- 「📁 保存路径」+「⬆ 从保存路径导入」；卡片右键 `⬇ 保存到本地文件夹（自动分类）` / `📂 在文件夹中显示` / `✎ 重命名` / `🗑 删除`
- 导出按 `角色 / 场景 / 素材 / 音频` 自动建子目录，同名同大小跳过
- 本地删除每 4 秒实时反映：列表自动移除 + 清缩略图缓存；收藏库失效条目打「文件已丢失」标 + 一键清理

**⑬ 修「切分到导演台后，时间线素材区不自动加载素材」（v1.9.9）**
- `refMap` 被 `sanitizeState` 每次 `store.set` 清空（只认平面数组，实际是每镜一组）→ 两种形态都处理
- 新增 `store.splitStamp`：方案变更时时间线丢缓存、按最新引用重新导入；并补"空着才自动补"的兜底（不覆盖手动选择）

## 2. 安装流程

### 2.1 环境要求

- ComfyUI **v0.3.4x 及以上**（本包在 0.34.6 实测通过；仅 nightly 修掉了「低于 8 步音频失真」的 bug）
- Python 3.10+（便携包自带 `python_embeded` 即可）
- 显存：**16GB 可跑** 864×480 / 608×1056 等档位；24GB+ 更从容
- 内存：≥32GB 建议（CLIP 文本编码器 int8 版载入约 30GB）

### 2.2 三步安装

**步骤 1 · 放包**

把 `ComfyUI_MRBoard_Next` 整个文件夹放到：

```
你的 ComfyUI 目录/
└── custom_nodes/
    └── ComfyUI_MRBoard_Next/     ← 放这里
        ├── __init__.py
        ├── nodes/    server/    web/js/
        ├── vendor/                ← H3 出片引擎已内嵌，不用单独装
        └── README.md              ← 本文件
```

> 便携包用户路径示例：`X:\ComfyUI_portable_TE\ComfyUI_portable_TE_v260619\ComfyUI\custom_nodes\ComfyUI_MRBoard_Next`
>
> ⚠️ 一定解压成**带全部子目录的完整文件夹**。如果只拷了 `__init__.py` 或少了 `vendor/`，出片会失败。

**步骤 2 · 装依赖（一次性）**

便携包根目录执行：

```bash
python_embeded\python.exe -m pip install imageio_ffmpeg Pillow opencv-python-headless "scenedetect>=0.6.4,<0.8"
```

| 依赖 | 作用 | 缺了会怎样 |
|---|---|---|
| `imageio_ffmpeg` | 剪辑合成 / 抽帧 / 缩略图 | 剪辑合成报「未找到 ffmpeg」 |
| `Pillow` | 占位图、读取图片尺寸 | 生图占位、SeedVR2 倍率换算失效 |
| `opencv-python-headless` | 时间线导入外部视频解码 | v2v / 外部视频导入失败 |
| `scenedetect` | 剪辑页「智能分割」 | 智能分割按钮不可用 |

**步骤 3 · 重启 ComfyUI**

关掉再启动（**改了 `nodes/*.py` 或 `server/*.py` 都必须重启**；只改前端 `web/js/*` 则 Ctrl+F5 即可）。

### 2.3 可选增强（按需安装）

| 想用的功能 | 额外需要 |
|---|---|
| **VOSR2 超分**（推荐，一步扩散，快且省显存） | ① `custom_nodes/ComfyUI-VOSR2` 节点包 ② 模型放 `models/vosr2/`：（`args.json`、`checkpoints/ema_model.safetensors`、`Qwen-Image-vae-2d/`、`dinov2_vitl14*.safetensors`）。**扁平布局或 `vosr2/VOSR2/` 子目录布局都认**。装好后生图面板会自动解除「VOSR2」选项的置灰 |
| **SeedVR2 超分** | `custom_nodes/ComfyUI-SeedVR2_VideoUpscaler`（节点 + CLI）+ `models/SEEDVR2/` 下的 DiT 与 VAE |
| **RTX VSR / FlashVSR 超分** | 随节点包附带，需 NVIDIA 显卡（RTX VSR 走 nvvfx 硬件加速） |
| **3D latent 二采** | `models/latent_upscale_models/minimax_h3_latent_upscaler_3d_bf16.safetensors`（⚠️ 2D 权重不可用） |
| **提示词优化** | `comfyUI-llama-TE` 包 + `models/LLM/*.gguf`（Qwen，可带 mmproj） |

### 2.4 升级 / 回滚

- **升级**：直接覆盖 `custom_nodes/ComfyUI_MRBoard_Next` 整个目录 → 重启 ComfyUI → 浏览器 **Ctrl+F5**。
- **回滚**：历史版本包都在 `custom_nodes/_packs/`（同时备份在 `Downloads`）。删掉现目录、解压旧包即可。
- ⚠️ 不要同时保留旧包 `ComfyUI_MRBoard` 与新包：H3 节点会重复注册（功能一致，以先加载的为准）。

## 3. 模型准备（关键）

所有模型放 ComfyUI 标准目录 `models/` 下，**本包会自动扫描，文件名对上就能用**。

### 3.1 必备（出片）

| 用途 | 目录 | 示例文件名 |
|---|---|---|
| H3 UNet（出片主模型） | `models/diffusion_models/` | `minimax_h3_fl2va_pruned_int8.safetensors` |
| Qwen3VL 文本编码器 | `models/text_encoders/` | `qwen3vl_32b_minimax_h3_int8_convrot.safetensors` |
| H3 视频 VAE | `models/vae/` | `minimax_h3_video_vae_fp16.safetensors` |
| H3 音频 VAE | `models/vae/` | `minimax_h3_audio_vae_fp32.safetensors` |

> ⚠️ **FL2VA 版模型支持全部 5 种模式**（T2V/I2V/FL2V/L2V/R2V），优先用它。
>
> ⚠️ **CLIP 量化档位决定"听不听话"**：H3 是 CFG=1.0（无负引导）模型，画面完全靠 CLIP 的语义理解。
> 本包默认优先选 **int8 版**（保真度最高）。如果你手动换成 `*nvfp4_awq`（4bit，省内存）而发现「画面不按提示词走」，换回 int8 即可。时间线面板的「🧠 模型」页会直接标出 ⚠ / ✓。

### 3.2 可选

| 用途 | 目录 | 备注 |
|---|---|---|
| Krea2 生图模型 | `models/diffusion_models/` | 角色/场景设定图、九宫格故事板 |
| 编辑 LoRA | `models/loras/` | 图片编辑（如 identity_edit） |
| 加速 LoRA | `models/loras/MiniMax-H3/` | 4/8 步蒸馏；强度在 **0.5–1.0** 之间扫，别盲套 alpha=8 |
| 本地 LLM | `models/LLM/` | Skill 提示词优化（GGUF） |

**检查方法**：打开时间线面板 → 顶部模型下拉 → 应该有文件列表。空的 = 路径不对或没重启。

## 5. 5 分钟快速上手

最短路径跑出第一段视频：

1. 点左侧 **📜 剧本** → 粘贴剧本 → 点「拆分分镜 → 自动时长 → 切分到导演台」
2. 点 **🎬 时间线** → 顶部「🎬 模式」选 **文生视频（纯文字）**
3. 在第一个镜头的提示词框里写好画面描述
4. 点该镜头的「出片」→ 等 1–3 分钟
5. 右侧「实时预览」框会实时显示采样画面，出片后原地变成视频预览

剧本模板：

```
【分镜1】
5秒 雨夜老街，红衣女子撑伞快步走过，镜头跟随推近，霓虹倒影在水面晃动。

【分镜2】
5秒 她停在路灯下回头，雨水顺着伞骨滑落，特写她的眼睛。
```

> 直接粘分镜、不写任何标记也能跑（纯 t2v 不需要素材）。

**底部**：运行日志（出片日志会回显「实际送模型的提示词」，可自查是否被污染）

### 6.1 素材/收藏的「保存路径 · 右键导出 · 本地删除检测」

**📁 保存路径**（素材库 / 收藏库顶部）：点它选一个本机文件夹（跨面板/跨会话记住）。用途：

| 操作 | 说明 |
|---|---|
| 卡片上 **右键** → `⬇ 保存到本地文件夹（自动分类）` | 把该资产另存到你选的目录，并按分类自动建子目录：`角色 / 场景 / 素材 / 音频`（有收藏就按收藏分类，没有就按扩展名）。同名同大小会自动跳过，不会堆一堆 `_2 _3` |
| 卡片上 **右键** → `📂 在文件夹中显示` | 打开系统文件管理器并定位到该文件 |
| 顶部 **⬆ 从保存路径导入** | 把保存路径里的图片/音频/视频（含子目录）一键导回资产文件夹 → 导入后立刻能在剧本/时间线里引用 |

**本地删除会实时反映**（不用重启、不用手动刷新）：素材库/收藏库挂载期间每 4 秒轻量重扫一次 ——

- 文件被外部删掉 → 素材库列表里自动消失，它的缩略图缓存也被清掉
- 收藏库里对应的条目 → 卡片打上红框「文件已丢失」，头部提示 `⚠ N 条文件已丢失`，点 **「🧹 清理失效收藏」** 一次性收拾干净

> 时间线 / 剪辑面板的素材区也会跟着重扫（切过去就是最新的）。

### 6.2 外部模型节点 / 第三方加速节点（内置加速自动让路）

「🎬 时间线」→「⚡ 加速」页最上方有 **「外部节点（模型 / 加速）」** 区块：

1. 点 **「🔗 扫描画布外部节点」**，列出当前画布上的：
   - **外部模型节点**：`UNETLoader` / `CheckpointLoader(Simple)` / GGUF / Nunchaku / `CLIPLoader` / `VAELoader` / `LoraLoader` 等 → 显示它选的文件名，点 **「采用」** 直接填进本节点「🧠 模型」页
     - 文件名里没有 `minimax` / `h3` 时会加 ⚠ 并在采用前二次确认（避免误把 SDXL 之类的模型当成 H3 模型）
   - **第三方加速节点**：SageAttention / BlockSparse、TeaCache 等缓存加速、`torch.compile`、FlashAttention、Nunchaku / torchao 量化、分块显存优化……
2. **只要画布上出现第三方加速节点，本节点的内置加速会自动整体失效**：`BlockSparse 加速` → 关闭、`TE-Speed 模式` → 关、`蒸馏 LoRA` → (无)。
   原因：内置与外部加速都会改写模型 / 噪声调度，叠加就是「双重加速」——画面发灰、显存反而爆。
3. 出片时底部日志会回执：`🔗 已检测到外部加速节点（…）→ 本节点内置加速已自动失效（原本启用：…）`，避免你疑惑"内置加速怎么没生效"。
4. 确实想叠加 → 勾 **「强制启用内置加速（忽略外部节点）」**，界面会提示"可能与外部加速重复叠加"。

> 后端也做了兜底：即使前端没传标记，构图阶段同样会让路 —— **送进队列的图里绝不会同时出现内置加速节点和外部加速**。

### 6.3 改名字（素材库 / 收藏库）· 一次点击全局同步

两个库的每张卡片 hover 后都多了一个 **✎** 按钮，点它名字会**就地变成输入框**（`回车`/点别处 = 确定，`Esc` = 取消）：

| 在哪个面板点 ✎ | 改的是什么 | 说明 |
|---|---|---|
| 🗂️ **素材库** | **磁盘文件名** | 保留扩展名；重名自动加 `_2`；不改内容、不覆盖已有文件 |
| ⭐ **收藏库** | **收藏名**（剧本里引用的名字） | 收藏名和文件名一致时会问一句「要不要连磁盘文件一起改」（确定 = 一起改，保持一致）；两者本来就不同名 → 只改收藏名 |

**改完立刻自动同步（不用刷新页面、不用重新拆剧本）**：

- 收藏库里指向该文件的条目 → `rel` / 名字一起更新（不会再出现"收藏还在、图打不开"）
- 公共前缀的 `<Picture N>` / `<Subject N>` 手动绑定、按名字的绑定 → rel 换到新文件
- `store.refMap`（每镜素材引用）、素材库自定义拖拽顺序 → 一起跟着改
- **剧本 / 公共前缀 / 每镜正文里的旧名字会自动改写为新名字**（标记不会"掉"），如果还出现了别的更长素材名（如 `林晚` 与 `林晚B`）会自动保护、不会被改坏
- 所有面板里已经打开的素材标记（token）与缩略图 → 实时指向新文件；时间线/分镜/剪辑的素材区也会重扫
- 缩略图缓存清掉旧 key，避免还挂着改名前的旧图

## 7. 完整流水线教程（6 步）

### 第 1 步 · 写剧本 📜

支持两种写法，**可以混用**：

```
<Subject 1> 小白兔
描述：雪白绒毛，红眼睛，长耳朵
<Picture 1> 森林草地场景
<Style 全局> 明亮卡通风格，柔和水彩质感

【分镜1】
5秒 森林草地上，小白兔蹦蹦跳跳摘下一朵野花。
【分镜2】
4秒 特写小白兔的耳朵竖起，警觉地看向远处。
```

- `【分镜N】` 或 `分镜N` 都认；时长写在正文里（`5秒`/`5s`）会自动提取
- **公共前缀**（`<Subject N>` / `<Picture N>` / `<Style 全局>` / 「角色 1 - 名字」）用「📦 自动抽公共前缀」一键抽出，之后会自动注入每个分镜
- 点「拆分分镜 → 自动时长 → 切分到导演台」，分镜自动进入 🎬 时间线

#### 公共前缀支持的写法（v1.9.6 大幅放宽）

公共前缀里**只要能被认出来的角色/场景就会各生成一张设定图**，每行 1 个条目。以下写法全部支持，可混用：

| 写法 | 例子 |
|---|---|
| 标签同行 | `<Subject 1> 林晚：28岁女性，及肩黑发` |
| 标签 + 逗号 | `<Subject 1> 林晚，28岁女性，及肩黑发` |
| 标签独占一行 | `<Subject 2>` ⏎ `名称：陆沉` ⏎ `描述：32岁男性，深灰风衣` |
| 标签独占一行 + 裸名 | `<Picture 1>` ⏎ `雨夜街头：霓虹倒影` |
| 序号角色行 | `角色1：林晚，28岁女性` ／ `场景二：雨夜街头，霓虹倒影` |
| 破折号写法 | `角色 1 - 张老汉：满脸皱纹` ／ `场景 1 - 破庙：残破的庙宇` |
| 小标题 + 列表 | `【角色】` ⏎ `- 林晚：28岁女性` ⏎ `1. 陆沉：32岁男性` |
| Markdown 小标题 | `## 一、人物` ／ `**场景设定**`（粗体、`#`、`-`/`*` 列表符都会自动剥掉） |
| 括号描述 | `- 林晚（28岁女性，及肩黑发）` |
| 裸键值（无小标题） | `林晚：28岁女性`（默认当角色；名字像地点如「雨夜街头」自动判为场景） |
| 全局风格 | `<Style 全局> 电影级写实，冷色调` ／ `<Style 全局>` ⏎ `冷色调` ／ `风格：冷色调` |

- 名字里的序号、`【】`、`**`、反引号都会自动清理；`角色之间的关系：…` 这类属性说明行不会被误当成角色
- 面板会实时显示 `识别到 N 角色 / M 场景`，鼠标悬停可看到**具体识别出了哪些名字 + 哪几行没认出来**；点「👁 预览」可先看清每条会喂给模型的 prompt
- 只有一条都认不出来时才会提示「没识别到」——此时把提示里那几行原文按上表改一下即可

### 第 2 步 · 分镜面板 🎞️（可选微调）

逐镜查看正文、改字、看每镜的时长与帧数、按素材匹配引用。

### 第 3 步 · 生成设定图 🎨（可选，但强烈建议）

角色形象固定下来，跨镜一致性会好很多：

1. 📜 剧本页点「⚡ 生成设定图并入收藏」（或去 🎨 生图页手动生成）
2. 生成结果进 ⭐ 收藏库
3. 剧本里写 `<Picture 1> 小白兔`，出片时会自动带上对应图

### 第 4 步 · 时间线逐镜出片 🎬

> 💡 **切分到导演台后，本镜素材会自动进九宫格（全部，不只是命中的那几张）**：
> 面板按 `store.refMap`（拆分的每镜引用）填左侧素材区，并且会**按正文里能看见的标记/名字再补一轮**——
> `<Picture N>`/`<Subject N>` 取素材库第 N 张（或手动绑定），正文里直接写名字的按收藏库/素材库同名解析。
> 若你手动挑过素材，自动补全**不会**覆盖你的选择；想重新按引用灌一遍，点该镜右上角「重置」。


顶部「🎬 模式」选任务类型（见第 8 节），然后在每个镜头块里：

| 控件 | 说明 |
|---|---|
| 素材九宫格 | i2v/fl2v/r2v 用；点格子选素材。**t2v 下会显示「⚠ 本模式不使用素材」**，明确告诉你图不会被用 |
| 提示词框 | 画面描述；支持 `@收藏名` 高亮为素材标记 |
| 实时预览 | 固定方框：生成中显示采样预览，出片后变视频（可播放/暂停），手动二采模式下带「✨ 二采高清放大」 |
| 秒 | 单镜时长（顶部开了「统一全局时长」时禁用） |
| 衔接下镜 | 勾选后把上一镜结尾写进本镜提示词，保持连贯 |
| 出片 / 复制 / 重置 / 删除 | 单镜操作 |

**整条连跑**：顶部「▶ 整条连跑」按顺序把所有镜头跑完（可勾「段间清理显存（每2镜）」防长时间连跑 OOM）。

**出片后必看日志**：会打印「实际送模型的提示词」，能一眼看出提示词有没有被污染、三段式结构对不对。

#### 🎙️ 声音 / 台词（治「说话乱说」）

点开「🎙️ 声音」页。H3 是**音视频联合生成**模型，不写声音字段它就会自己补人声 → 表现为"张嘴说胡话"。本包自动按官方三段式组装：

```
integrated_multimodal_description:  画面 + 动作 + 镜头 + 说话人 (S1) + 台词 [Chinese] xxx
overall_soundscape:                 环境音（不含对白）
non_diegetic_music:                 画外配乐（或 N/A）
```

三条硬规则（本包已自动处理，知道就行）：

- 台词**只能用** `[Chinese] 台词` 这种写法，**不能用双引号**（双引号在 H3 里是"画面上可见的字"，会渲染成字幕）
- 说话人 (S1)/(S2) 由公共前缀角色顺序分配，**跨镜头天然一致**，不要手动乱编号
- **无台词必须显式声明**，否则模型照样安排人说话

#### 📐 画质与步数

| 档位 | 步数 | 采样器 | 说明 |
|---|---|---|---|
| 草稿 | 6 | res_multistep / simple | 需配蒸馏 LoRA，强度 0.5–1.0 |
| 标准（推荐） | 12 | res_multistep / simple | cfg=1、shift 保持训练值（视频 12 / 音频 3） |
| 成品 | 20 | res_multistep / simple | 出片后自动二采 |

> ⚠️ **低于 8 步音频会失真** —— 这是 ComfyUI 稳定版的 bug（commit `bdcb886`，仅 nightly 修复）。
> 本包内置**低步数音频护栏**：步数低于安全线会自动抬到 8 步并在日志回执。
> 想真跑 4–6 步：把 ComfyUI 升到 nightly，再到「🎙️ 声音」页调低安全线/关掉护栏。

## 8. 出片模式对照表

| 模式 | 需要素材 | 素材区形态 | 构图（自动） | 用途 |
|---|---|---|---|---|
| **t2v** 文生视频 | 不需要 | 无素材区 | 单个 Director，**零素材节点** | 纯文字描述出片 |
| **i2v** 首帧生视频 | 1 张图 | **1 个框：首帧** | 1× LoadImage + GroupImageToVideo | 用设定图作为起始帧 |
| **fl2v** 首尾帧 | 1–2 张图 | **2 个框：首帧 / 尾帧** | 2× LoadImage | 指定起点与终点，中间自然过渡 |
| **fl2v_tail** 尾帧 | 1 张图（尾帧） | **1 个框：尾帧** | 1× LoadImage | 反推走到该定格帧 |
| **r2v** 参考主体 | N 张图 | 九宫格 + 音视小格 | N× LoadImage + GroupReferenceToVideo | 多参考图保持主体/风格一致 |

> 首尾帧一族（i2v / fl2v / fl2v_tail）的素材区**只有首帧/尾帧那几个框**，就是该模式全部的图；
> FL2V 少填一张也能出片：只填首帧 → 自动退化成 I2V；只填尾帧 → 自动退化成 L2V（日志会回执说明）。

**互不串扰（已硬保证）**：t2v 即使误传了首帧/尾帧/参考图，后端与构图层都会剔除并回传 `dropped` 列表；给 i2v 多传参考图会被忽略；i2v 不会串到 ReferenceToVideo 组。

## 9. 放大与超分（倍率统一说明）

三个入口都带「**倍率**」参数（1–4，超出自动夹取）：**生图面板**、**时间线二采**、**剪辑超分**。

**倍率语义（各引擎一致，不用记参数差异）**：

| 引擎 | 倍率含义 | 特点 |
|---|---|---|
| 内置精修（hires-fix） | latent 放大倍数 | 需 Krea2 模型；二次采样，画质提升明显 |
| SeedVR2 | **目标短边 = 源短边 × 倍率** | 质量佳但慢；图片按实际像素算，视频用 ffprobe 读 |
| RTX VSR | 直接倍数 | 快（N 卡硬件） |
| TE-FlashVSR | 直接倍数 | 快，需模型 |
| **VOSR2** | 直接整数倍数 | **一步扩散超分，比 SeedVR2 快且省显存**（推荐做 H3 二采平替） |

- **生图**：勾「✨ 画质增强」选引擎 + 倍率；已有图可用「✨ 再次增强」二次处理
- **时间线**：二采行选「关闭二采 / 出片后自动 / 确定后手动」+ 引擎 + 倍率；手动模式下预览框会出现「✨ 二采高清放大」
- **剪辑**：选素材 → 选「超分方案」+ 倍率 → 「✨ 超分放大」（会先弹文件夹让选保存位置）

VOSR2 未就绪时，生图面板的选项会**自动置灰并说明原因**（模型文件或节点缺失），不会"点了没反应"。

### 10.3 LoRA（点一下就能用 · 对所有生图模式生效）

在「🎨 生图」面板点 **「🎚 选择 LoRA」** → 弹出列表（来源 = 上面「LoRA 文件夹」里选定的目录）：

- **点一项即生效**；可多选，最多同时叠 4 个；旁边「强度」输入框决定新选中项用多大（0–2，默认 1）
- 浮层里有搜索框 + 「↻ 刷新」；「清空」取消全部；选完点「完成」关掉（也可以不关，接着点下一个）
- 顶部会显示 `共 N 个 · 可加载 M 个 · ⚠不可加载 K 个 · 已选 x/4`

**LoRA 生效范围**：文生图 / 图生图 / 参考生图 / 编辑图 **四种模式全部生效**（LoRA 挂在 UNETLoader → KSampler 之间，开启「画质增强」时二次采样同样走 LoRA）。**剧本面板的「生成设定图并入收藏」、流水线批量生图、Skill 面板的「生成对应资产」也都吃这个选择。**

⚠️ **LoRA 必须放在 ComfyUI 能搜索到的目录**，否则加载会失败（表现为 `prompt_outputs_failed_validation`）：

| 放哪里 | 说明 |
|---|---|
| `ComfyUI/models/loras/`（可带子目录） | 默认，直接可用 |
| 其他磁盘/目录 | 需在 `extra_model_paths.yaml` 里登记该目录，然后重启 ComfyUI |

面板已经帮你拦住了：不在 ComfyUI 搜索路径里的 LoRA 会**置灰并标注「不可加载」**，点它只会提示你怎么修；即使强行传进去，后端也会**忽略并把名字回报**（不会让你以为"选了却在起作用"）。

**验证 LoRA 真的生效**：同种子、同提示词分别"不带 LoRA / 带 LoRA"各生成一张，两张图应当明显不同（实测平均像素差可到 60+）。

### 10.4 分镜九宫格故事板（切格即 i2v 首帧）

| 预设 | 整图尺寸 | 单格 | 适合 |
|---|---|---|---|
| ⑪ 写实电影感 3×3 | 1536×1536 | 512×512 | 剧情 / 悬疑 / 文艺 |
| ⑫ 日式动漫 3×3 | 1536×1536 | 512×512 | 番剧 / 漫剧 |
| ⑬ 竖屏短剧 3×3 | **1152×2048** | **384×683** | 竖屏短剧（抖音/快手） |
| ⑭ 横屏 16:9 3×3 | 2560×1440 | 853×480 | B 站 / TVC / 横屏剧 |

**两条必须知道的工程规则**：

1. **严格 3×3 等分时，单格宽高比 ≡ 整图宽高比。** 要竖屏 9:16 首帧，就**直接出 9:16 整图**，切格即得，不用裁切。
2. **i2v 首帧要求单格短边 > 300px。** 这就是竖屏档位定在 1152×2048 的原因（单格 384×683）。

**用法**：🎨 生图 → 📋 提示词预设 → 选 ⑬ → 替换【角色描述】/【场景】→ 生成 → 得到一张 3×3 故事板 → 切成 9 张 → 时间线选 **i2v** 模式，把单格作为首帧逐镜出片。

模板里已写死这些约束（Krea2 没有负面提示词通道，所以用正向禁令表达）：同一角色跨 9 格一致、严格 3×3 等分、细浅分隔线、每格主体完整不裁头、**全图禁止文字/字幕/箭头/水印/厚边框/网格错位**、九格按「建立环境→引入主角→触发事件→冲突升级→转折→情绪特写→行动推进→危机反转→收束钩子」推进。

## 11. 剪辑面板（剪映式）

### 11.1 导入（只有一个入口）

**📂 导入本地视频** —— 点它直接弹文件多选；点右边 `▾` 可选「选文件夹（递归）」或「浏览器上传」。
（旧版的「导入文件 / 导入文件夹 / 浏览器导入」三个重复按钮已合并。）

### 11.2 时间轴操作

| 操作 | 怎么做 |
|---|---|
| 加片段 | 素材区选中素材 → 「＋ V1 主轨 / ＋ V2 副轨 / ＋ A1 音频轨」；或「⏩ 全部入轨」一键按顺序铺满 V1 |
| 定位 | 点时间标尺任意位置 → 播放头跳过去（同时把预览 seek 到对应位置）；按住拖动可连续拖播放头 |
| 裁剪 | **拖片段左右两端的把手**（吸附 0.1s）；拖的时候片段会**逐帧跟着变宽变窄**，旁边浮层实时显示「入点/出点 + 当前时长」；也可在下方编辑栏直接输入入点/出点秒数 |
| 分割 | 把播放头放片段内部 → 编辑栏「✂ 分割」或按 `S` |
| 复制 / 删除 | 编辑栏「⧉ 复制」「✕ 删除片段」，或快捷键 |
| 排序 | 拖拽片段，或用片段上的 `◀ ▶` 微调 |
| 变速 | 选中片段 → 编辑栏「变速」选 0.5× / 0.75× / 1.25× / 1.5× / 2× |
| 音量 / 静音 | 选中片段 → 编辑栏音量滑杆（0–3，1=原声）+ 勾「静音」 |

片段宽度**按时长等比**（30px = 1 秒）；带 `✂` 表示已裁剪，带 `1.5×` 表示已变速，带 `🔇` 表示已静音。

### 11.3 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 预览播放 / 暂停（没加载视频且主轨有片段时，直接连播主轨） |
| `← / →` | 播放头 ∓0.1 秒（`Shift` 为 ∓1 秒）—— 跟手、逐帧微调 |
| `Alt + ← / →` | 微调**选中片段**的入点（每秒 0.1 秒） |
| `Delete` / `Backspace` | 删除选中片段 |
| `Ctrl + D` | 复制选中片段 |
| `S` | 在播放头位置分割 |
| `Ctrl + Z` | 剪辑撤销 |
| `Ctrl + Shift + Z` / `Ctrl + Y` | 剪辑重做 |
| `Ctrl + S` | 合成成片 |
| `Esc` | 取消选中 |

> 在输入框里打字时快捷键自动让位，不会误删片段。
> ⚠️ `Ctrl + Z` 同时也是 ComfyUI 自己的「撤销工作流」（全局绑定），按一次会**同时**撤销剪辑和画布上的上一步操作 —— 这是 ComfyUI 的全局行为，用面板上的「↩ 撤销」按钮可只撤销剪辑。

### 11.4 为什么现在拖拽"丝滑"

- 拖拽期间**不做任何全量重绘**：每个动画帧只改被拖那一个片段的宽度 + 刷新浮层文字（用 `requestAnimationFrame` 合并高频 `pointermove`）；
- 标尺刻度按"总时长"缓存，总时长没变就不重建（避免每次拖拽重建上百个 DOM 节点）；
- 素材区点选只切换选中样式、**复用已有卡片 DOM**（不再重建整排缩略图，素材上百个也不卡）；
- 「⏩ 全部入轨」「↻ 刷新」改为**批量一次渲染**，探时长结果带缓存（同一素材不重复 ffprobe）；
- 预览播放 / 拖动播放头时，播放头只改 `left` 一个属性（零重排），并跟着视频播放实时走。

### 11.5 合成

选好轨道 → 可选背景音乐（单个文件或多段 A1 轨）→ 「🎬 合成成片」。
后端会逐段按 `入点/出点 + 变速 + 音量` 重编码，再无损拼接、混音，输出到 `input/{资产文件夹}/video/`。

## 14. 缓存与清理

### 时间线「🗑 清空」会自动清三类缓存

点一次「🗑 清空」= 清空分镜 + 清缓存，避免旧缓存影响后续生成：

| 清什么 | 为什么 |
|---|---|
| 面板内状态（分镜配置 / 选择 / 出片预览 / 实时预览轮询） | 切模式或重跑时不会残留上一轮的预览帧 |
| `output/mrnext_preview/*.jpg`（采样实时预览图） | 残留会让下一轮在写出首张预览前显示上一轮的旧帧 |
| `input/{folder}/_plan.json` → **归档**为 `_plan.prev.json` | 残留会让节点认为还有分镜计划，从而重跑旧计划干扰新生成 |
| `output/mrnext_thumbs/*.jpg`（素材缩略图） | 源文件变了但缓存在，会显示旧图 |

日志会回执：`🧹 缓存已清理：采样预览图 N · 素材缩略图 M · 旧计划已归档`。

### 其他需要手动清的情况

| 位置 | 何时清 |
|---|---|
| `output/mrnext_preview/` | 觉得实时预览串了别的任务 |
| `output/mrnext_thumbs/` | 缩略图与素材对不上 |
| `user/mrboard_favorites_next.json` | 收藏库乱了（删掉会重建） |
| 浏览器 `localStorage` 的 `mrnext.*` | 面板状态异常（也可在节点报错条上点「🧹 重置面板状态并重新加载」） |

## 15. 常见问题排查

| 症状 | 原因 | 解决 |
|---|---|---|
| 画布搜不到节点 | 包没解压完整 / 没重启 | 检查 `custom_nodes/ComfyUI_MRBoard_Next/__init__.py` 与 `vendor/` 是否存在，重启 ComfyUI |
| 面板全空白 | 浏览器缓存旧前端 | **Ctrl+F5 硬刷新**；仍空白就 F12 看 Console 里的 `MRBoardNext` 报错 |
| 版本徽章不是最新 | 同上 | Ctrl+F5；确认 `main.js` 顶部 `MRNEXT_VERSION` 与包版本一致 |
| 模型下拉是空的 | 模型放错目录 | 对照第 3 节路径表，重启一次 |
| 面板下方一大片空白 | 旧版布局问题 | v1.9.1+ 已修（编辑区撑满），升级即可 |
| 生图报 `got an unexpected keyword argument 'enhance_scale'` | v1.9.0–1.9.3 的签名 bug | 升级到 **v1.9.4+** |
| 选「VOSR2」没反应 / 提示缺失 | 节点包或模型不全 | 装 `ComfyUI-VOSR2` + `models/vosr2/` 模型后重启；面板会给出具体缺什么 |
| 文生视频画面不按提示词走 | ① CLIP 用了 4bit `nvfp4_awq` ② 旧版英文兜底稀释中文 | ① 「🧠 模型」换成 int8 版 ② 升级到 v1.7.7+ |
| 出片时预览显示的还是上一轮的图 | 旧版预览没绑定本次任务 | 升级到 v1.9.0+（预览带 `?since=` 只认本次生成的图） |
| 画面里出现奇怪 token（如 `@image#1:xx.png`） | 粘贴进了"虚拟引用" | v1.7.5+ 已在四层净化（粘贴入口 / store / 发送层 / 后端）；升级即可 |
| 人物张嘴说胡话 / 说话乱说 | 提示词缺三段式声音字段 | v1.7.6+ 已自动组装三段式；确认「🎙️ 声音」页没关掉 |
| 音轨失真 / 变噪音 | 步数 <8（ComfyUI 稳定版 bug） | 用 8 步以上，或升 nightly；护栏也会自动抬步数 |
| 想跑 4–6 步加速 | 需 nightly + 蒸馏 LoRA | 升 nightly；LoRA 强度在 0.5–1.0 扫 |
| 节点被预览大图撑高 | 旧版会给 OUTPUT_NODE 加画布预览 | v1.7.8+ 已屏蔽 |
| 长时段连跑 OOM | 显存累积 | 时间线勾「段间清理显存（每2镜）」 |
| 出片很慢 | 正常 | 864×480 / 12 步在 16G 卡上约 1–3 分钟/镜 |
| 剪辑合成报未找到 ffmpeg | 缺 `imageio_ffmpeg` | 按第 2.2 节装依赖 |
| 剪辑导入按钮点了没反应 | 系统文件选择框被拦 | 点 `▾` 用「浏览器上传」兜底 |
