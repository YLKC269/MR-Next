## 2. 安装流程

### 2.1 环境要求

- ComfyUI **v0.3.4x 及以上**（本包在 0.34.6 实测通过；仅 nightly 修掉了「低于 8 步音频失真」的 bug）
- Python 3.10+（便携包自带 `python_embeded` 即可）
- 显存：**16GB 可跑** 864×480 / 608×1056 等档位；24GB+ 更从容
- 内存：≥32GB 建议（CLIP 文本编码器 int8 版载入约 30GB）

### 2.2 三步安装

**步骤 1 · 放包**

把 `ComfyUI_MRBoard_Next` 整个文件夹放到：

```
你的 ComfyUI 目录/
└── custom_nodes/
    └── ComfyUI_MRBoard_Next/     ← 放这里
        ├── __init__.py
        ├── nodes/    server/    web/js/
        ├── vendor/                ← H3 出片引擎已内嵌，不用单独装
        └── README.md              ← 本文件
```

> 便携包用户路径示例：`X:\ComfyUI_portable_TE\ComfyUI_portable_TE_v260619\ComfyUI\custom_nodes\ComfyUI_MRBoard_Next`
>
> ⚠️ 一定解压成**带全部子目录的完整文件夹**。如果只拷了 `__init__.py` 或少了 `vendor/`，出片会失败。

**步骤 2 · 装依赖（一次性）**

便携包根目录执行：

```bash
python_embeded\python.exe -m pip install imageio_ffmpeg Pillow opencv-python-headless "scenedetect>=0.6.4,<0.8"
```

| 依赖 | 作用 | 缺了会怎样 |
|---|---|---|
| `imageio_ffmpeg` | 剪辑合成 / 抽帧 / 缩略图 | 剪辑合成报「未找到 ffmpeg」 |
| `Pillow` | 占位图、读取图片尺寸 | 生图占位、SeedVR2 倍率换算失效 |
| `opencv-python-headless` | 时间线导入外部视频解码 | v2v / 外部视频导入失败 |
| `scenedetect` | 剪辑页「智能分割」 | 智能分割按钮不可用 |

**步骤 3 · 重启 ComfyUI**

关掉再启动（**改了 `nodes/*.py` 或 `server/*.py` 都必须重启**；只改前端 `web/js/*` 则 Ctrl+F5 即可）。

### 2.3 可选增强（按需安装）

| 想用的功能 | 额外需要 |
|---|---|
| **VOSR2 超分**（推荐，一步扩散，快且省显存） | ① `custom_nodes/ComfyUI-VOSR2` 节点包 ② 模型放 `models/vosr2/`：（`args.json`、`checkpoints/ema_model.safetensors`、`Qwen-Image-vae-2d/`、`dinov2_vitl14*.safetensors`）。**扁平布局或 `vosr2/VOSR2/` 子目录布局都认**。装好后生图面板会自动解除「VOSR2」选项的置灰 |
| **SeedVR2 超分** | `custom_nodes/ComfyUI-SeedVR2_VideoUpscaler`（节点 + CLI）+ `models/SEEDVR2/` 下的 DiT 与 VAE |
| **RTX VSR / FlashVSR 超分** | 随节点包附带，需 NVIDIA 显卡（RTX VSR 走 nvvfx 硬件加速） |
| **3D latent 二采** | `models/latent_upscale_models/minimax_h3_latent_upscaler_3d_bf16.safetensors`（⚠️ 2D 权重不可用） |
| **提示词优化** | `comfyUI-llama-TE` 包 + `models/LLM/*.gguf`（Qwen，可带 mmproj） |

### 2.4 升级 / 回滚

- **升级**：直接覆盖 `custom_nodes/ComfyUI_MRBoard_Next` 整个目录 → 重启 ComfyUI → 浏览器 **Ctrl+F5**。
- **回滚**：历史版本包都在 `custom_nodes/_packs/`（同时备份在 `Downloads`）。删掉现目录、解压旧包即可。
- ⚠️ 不要同时保留旧包 `ComfyUI_MRBoard` 与新包：H3 节点会重复注册（功能一致，以先加载的为准）。

## 3. 模型准备（关键）

所有模型放 ComfyUI 标准目录 `models/` 下，**本包会自动扫描，文件名对上就能用**。

### 3.1 必备（出片）

| 用途 | 目录 | 示例文件名 |
|---|---|---|
| H3 UNet（出片主模型） | `models/diffusion_models/` | `minimax_h3_fl2va_pruned_int8.safetensors` |
| Qwen3VL 文本编码器 | `models/text_encoders/` | `qwen3vl_32b_minimax_h3_int8_convrot.safetensors` |
| H3 视频 VAE | `models/vae/` | `minimax_h3_video_vae_fp16.safetensors` |
| H3 音频 VAE | `models/vae/` | `minimax_h3_audio_vae_fp32.safetensors` |

> ⚠️ **FL2VA 版模型支持全部 5 种模式**（T2V/I2V/FL2V/L2V/R2V），优先用它。
>
> ⚠️ **CLIP 量化档位决定"听不听话"**：H3 是 CFG=1.0（无负引导）模型，画面完全靠 CLIP 的语义理解。
> 本包默认优先选 **int8 版**（保真度最高）。如果你手动换成 `*nvfp4_awq`（4bit，省内存）而发现「画面不按提示词走」，换回 int8 即可。时间线面板的「🧠 模型」页会直接标出 ⚠ / ✓。

### 3.2 可选

| 用途 | 目录 | 备注 |
|---|---|---|
| Krea2 生图模型 | `models/diffusion_models/` | 角色/场景设定图、九宫格故事板 |
| 编辑 LoRA | `models/loras/` | 图片编辑（如 identity_edit） |
| 加速 LoRA | `models/loras/MiniMax-H3/` | 4/8 步蒸馏；强度在 **0.5–1.0** 之间扫，别盲套 alpha=8 |
| 本地 LLM | `models/LLM/` | Skill 提示词优化（GGUF） |

**检查方法**：打开时间线面板 → 顶部模型下拉 → 应该有文件列表。空的 = 路径不对或没重启。

## 5. 5 分钟快速上手

最短路径跑出第一段视频：

1. 点左侧 **📜 剧本** → 粘贴剧本 → 点「拆分分镜 → 自动时长 → 切分到导演台」
2. 点 **🎬 时间线** → 顶部「🎬 模式」选 **文生视频（纯文字）**
3. 在第一个镜头的提示词框里写好画面描述
4. 点该镜头的「出片」→ 等 1–3 分钟
5. 右侧「实时预览」框会实时显示采样画面，出片后原地变成视频预览

剧本模板：

```
【分镜1】
5秒 雨夜老街，红衣女子撑伞快步走过，镜头跟随推近，霓虹倒影在水面晃动。

【分镜2】
5秒 她停在路灯下回头，雨水顺着伞骨滑落，特写她的眼睛。
```

> 直接粘分镜、不写任何标记也能跑（纯 t2v 不需要素材）。

## 7. 完整流水线教程（6 步）

### 第 1 步 · 写剧本 📜

支持两种写法，**可以混用**：

```
<Subject 1> 小白兔
描述：雪白绒毛，红眼睛，长耳朵
<Picture 1> 森林草地场景
<Style 全局> 明亮卡通风格，柔和水彩质感

【分镜1】
5秒 森林草地上，小白兔蹦蹦跳跳摘下一朵野花。
【分镜2】
4秒 特写小白兔的耳朵竖起，警觉地看向远处。
```

- `【分镜N】` 或 `分镜N` 都认；时长写在正文里（`5秒`/`5s`）会自动提取
- **公共前缀**（`<Subject N>` / `<Picture N>` / `<Style 全局>` / 「角色 1 - 名字」）用「📦 自动抽公共前缀」一键抽出，之后会自动注入每个分镜
- 点「拆分分镜 → 自动时长 → 切分到导演台」，分镜自动进入 🎬 时间线

### 第 2 步 · 分镜面板 🎞️（可选微调）

逐镜查看正文、改字、看每镜的时长与帧数、按素材匹配引用。

### 第 3 步 · 生成设定图 🎨（可选，但强烈建议）

角色形象固定下来，跨镜一致性会好很多：

1. 📜 剧本页点「⚡ 生成设定图并入收藏」（或去 🎨 生图页手动生成）
2. 生成结果进 ⭐ 收藏库
3. 剧本里写 `<Picture 1> 小白兔`，出片时会自动带上对应图

### 第 4 步 · 时间线逐镜出片 🎬

顶部「🎬 模式」选任务类型（见第 8 节），然后在每个镜头块里：

| 控件 | 说明 |
|---|---|
| 素材九宫格 | i2v/fl2v/r2v 用；点格子选素材。**t2v 下会显示「⚠ 本模式不使用素材」**，明确告诉你图不会被用 |
| 提示词框 | 画面描述；支持 `@收藏名` 高亮为素材标记 |
| 实时预览 | 固定方框：生成中显示采样预览，出片后变视频（可播放/暂停），手动二采模式下带「✨ 二采高清放大」 |
| 秒 | 单镜时长（顶部开了「统一全局时长」时禁用） |
| 衔接下镜 | 勾选后把上一镜结尾写进本镜提示词，保持连贯 |
| 出片 / 复制 / 重置 / 删除 | 单镜操作 |

**整条连跑**：顶部「▶ 整条连跑」按顺序把所有镜头跑完（可勾「段间清理显存（每2镜）」防长时间连跑 OOM）。

**出片后必看日志**：会打印「实际送模型的提示词」，能一眼看出提示词有没有被污染、三段式结构对不对。

#### 🎙️ 声音 / 台词（治「说话乱说」）

点开「🎙️ 声音」页。H3 是**音视频联合生成**模型，不写声音字段它就会自己补人声 → 表现为"张嘴说胡话"。本包自动按官方三段式组装：

```
integrated_multimodal_description:  画面 + 动作 + 镜头 + 说话人 (S1) + 台词 [Chinese] xxx
overall_soundscape:                 环境音（不含对白）
non_diegetic_music:                 画外配乐（或 N/A）
```

三条硬规则（本包已自动处理，知道就行）：

- 台词**只能用** `[Chinese] 台词` 这种写法，**不能用双引号**（双引号在 H3 里是"画面上可见的字"，会渲染成字幕）
- 说话人 (S1)/(S2) 由公共前缀角色顺序分配，**跨镜头天然一致**，不要手动乱编号
- **无台词必须显式声明**，否则模型照样安排人说话

#### 📐 画质与步数

| 档位 | 步数 | 采样器 | 说明 |
|---|---|---|---|
| 草稿 | 6 | res_multistep / simple | 需配蒸馏 LoRA，强度 0.5–1.0 |
| 标准（推荐） | 12 | res_multistep / simple | cfg=1、shift 保持训练值（视频 12 / 音频 3） |
| 成品 | 20 | res_multistep / simple | 出片后自动二采 |

> ⚠️ **低于 8 步音频会失真** —— 这是 ComfyUI 稳定版的 bug（commit `bdcb886`，仅 nightly 修复）。
> 本包内置**低步数音频护栏**：步数低于安全线会自动抬到 8 步并在日志回执。
> 想真跑 4–6 步：把 ComfyUI 升到 nightly，再到「🎙️ 声音」页调低安全线/关掉护栏。

## 8. 出片模式对照表

| 模式 | 需要素材 | 构图（自动） | 用途 |
|---|---|---|---|
| **t2v** 文生视频 | 不需要 | 单个 Director，**零素材节点** | 纯文字描述出片 |
| **i2v** 首帧生视频 | 1 张图 | 1× LoadImage + GroupImageToVideo | 用设定图/九宫格单格作为起始帧 |
| **fl2v** 首尾帧 | 2 张图 | 2× LoadImage | 指定起点与终点，中间自然过渡 |
| **fl2v_tail** 尾帧 | 1 张图（尾帧） | 1× LoadImage | 反推走到该定格帧 |
| **r2v** 参考主体 | N 张图 | N× LoadImage + GroupReferenceToVideo | 多参考图保持主体/风格一致 |

**互不串扰（已硬保证）**：t2v 即使误传了首帧/尾帧/参考图，后端与构图层都会剔除并回传 `dropped` 列表；给 i2v 多传参考图会被忽略；i2v 不会串到 ReferenceToVideo 组。

## 9. 放大与超分（倍率统一说明）

三个入口都带「**倍率**」参数（1–4，超出自动夹取）：**生图面板**、**时间线二采**、**剪辑超分**。

**倍率语义（各引擎一致，不用记参数差异）**：

| 引擎 | 倍率含义 | 特点 |
|---|---|---|
| 内置精修（hires-fix） | latent 放大倍数 | 需 Krea2 模型；二次采样，画质提升明显 |
| SeedVR2 | **目标短边 = 源短边 × 倍率** | 质量佳但慢；图片按实际像素算，视频用 ffprobe 读 |
| RTX VSR | 直接倍数 | 快（N 卡硬件） |
| TE-FlashVSR | 直接倍数 | 快，需模型 |
| **VOSR2** | 直接整数倍数 | **一步扩散超分，比 SeedVR2 快且省显存**（推荐做 H3 二采平替） |

- **生图**：勾「✨ 画质增强」选引擎 + 倍率；已有图可用「✨ 再次增强」二次处理
- **时间线**：二采行选「关闭二采 / 出片后自动 / 确定后手动」+ 引擎 + 倍率；手动模式下预览框会出现「✨ 二采高清放大」
- **剪辑**：选素材 → 选「超分方案」+ 倍率 → 「✨ 超分放大」（会先弹文件夹让选保存位置）

VOSR2 未就绪时，生图面板的选项会**自动置灰并说明原因**（模型文件或节点缺失），不会"点了没反应"。

## 10. 生图面板 & 分镜九宫格故事板

### 10.1 四种生图模式

| 标签 | 模式 | 说明 |
|---|---|---|
| ✨ 文生图 | t2i | 纯提示词出图 |
| 🖼️ 图生图 | i2i | 给原图 + 强度（0.05–0.95）改写 |
| 🌟 参考生图 | ref | 1–3 张参考图锁角色/风格/场景 |
| ✏️ 编辑图 | edit | 原图 + 编辑 LoRA 做定向修改 |

### 10.2 提示词预设（14 条）

「📋 提示词预设」里包含角色三视图、五格资产板、UE5 角色表、表情表、服装分层拆解，以及 **4 套分镜九宫格故事板**。带尺寸的预设点「使用」会**自动套用出图尺寸**。

### 10.3 分镜九宫格故事板（切格即 i2v 首帧）

| 预设 | 整图尺寸 | 单格 | 适合 |
|---|---|---|---|
| ⑪ 写实电影感 3×3 | 1536×1536 | 512×512 | 剧情 / 悬疑 / 文艺 |
| ⑫ 日式动漫 3×3 | 1536×1536 | 512×512 | 番剧 / 漫剧 |
| ⑬ 竖屏短剧 3×3 | **1152×2048** | **384×683** | 竖屏短剧（抖音/快手） |
| ⑭ 横屏 16:9 3×3 | 2560×1440 | 853×480 | B 站 / TVC / 横屏剧 |

**两条必须知道的工程规则**：

1. **严格 3×3 等分时，单格宽高比 ≡ 整图宽高比。** 要竖屏 9:16 首帧，就**直接出 9:16 整图**，切格即得，不用裁切。
2. **i2v 首帧要求单格短边 > 300px。** 这就是竖屏档位定在 1152×2048 的原因（单格 384×683）。

**用法**：🎨 生图 → 📋 提示词预设 → 选 ⑬ → 替换【角色描述】/【场景】→ 生成 → 得到一张 3×3 故事板 → 切成 9 张 → 时间线选 **i2v** 模式，把单格作为首帧逐镜出片。

模板里已写死这些约束（Krea2 没有负面提示词通道，所以用正向禁令表达）：同一角色跨 9 格一致、严格 3×3 等分、细浅分隔线、每格主体完整不裁头、**全图禁止文字/字幕/箭头/水印/厚边框/网格错位**、九格按「建立环境→引入主角→触发事件→冲突升级→转折→情绪特写→行动推进→危机反转→收束钩子」推进。

## 11. 剪辑面板（剪映式）

### 11.1 导入（只有一个入口）

**📂 导入本地视频** —— 点它直接弹文件多选；点右边 `▾` 可选「选文件夹（递归）」或「浏览器上传」。
（旧版的「导入文件 / 导入文件夹 / 浏览器导入」三个重复按钮已合并。）

### 11.2 时间轴操作

| 操作 | 怎么做 |
|---|---|
| 加片段 | 素材区选中素材 → 「＋ V1 主轨 / ＋ V2 副轨 / ＋ A1 音频轨」；或「⏩ 全部入轨」一键按顺序铺满 V1 |
| 定位 | 点时间标尺任意位置 → 播放头跳过去（同时把预览 seek 到对应位置） |
| 裁剪 | **拖片段左右两端的把手**（吸附 0.1s）；也可在下方编辑栏直接输入入点/出点秒数 |
| 分割 | 把播放头放片段内部 → 编辑栏「✂ 分割」或按 `S` |
| 复制 / 删除 | 编辑栏「⧉ 复制」「✕ 删除片段」，或快捷键 |
| 排序 | 拖拽片段，或用片段上的 `◀ ▶` 微调 |
| 变速 | 选中片段 → 编辑栏「变速」选 0.5× / 0.75× / 1.25× / 1.5× / 2× |
| 音量 / 静音 | 选中片段 → 编辑栏音量滑杆（0–3，1=原声）+ 勾「静音」 |

片段宽度**按时长等比**（30px = 1 秒）；带 `✂` 表示已裁剪，带 `1.5×` 表示已变速，带 `🔇` 表示已静音。

### 11.3 快捷键

| 键 | 作用 |
|---|---|
| `空格` | 预览播放 / 暂停（没加载视频且主轨有片段时，直接连播主轨） |
| `Delete` / `Backspace` | 删除选中片段 |
| `Ctrl + D` | 复制选中片段 |
| `S` | 在播放头位置分割 |
| `Ctrl + Z` | 撤销 |
| `Ctrl + Shift + Z` / `Ctrl + Y` | 重做 |

> 在输入框里打字时快捷键自动让位，不会误删片段。

### 11.4 合成

选好轨道 → 可选背景音乐（单个文件或多段 A1 轨）→ 「🎬 合成成片」。
后端会逐段按 `入点/出点 + 变速 + 音量` 重编码，再无损拼接、混音，输出到 `input/{资产文件夹}/video/`。

## 12. Skill 提示词优化

**② 本地模型**：选 GGUF → 会自动套最优参数（上下文/采样/mmproj）→ 勾「选模型自动加载」或点「加载模型」（首载 1–5 分钟）。

**③ 优化**：优化方向（含 H3 官方 T2V/I2V/FL2V/L2V/R2V 模板、角色三视图、分镜脚本）→ 填待优化内容 → 「开始优化」。勾「接续推理直到完整」可在被 token 上限截断时自动续写。

**④ 推理过程**（右下角）：勾了「② 本地模型 → 思考模式」时，模型的分析过程会显示在这里，方便判断它有没有理解偏；没开思考模式会提示你开启。

优化结果可直接「结果 → 剧本」回填，或「⚡ 生成对应资产」自动识别里面的角色/场景定义并出设定图入库。

## 13. 主题外观与缩放适配

点顶部主题按钮循环切换：

| 主题 | 效果 |
|---|---|
| 🎨 默认 | 冷色深蓝 + 你自选的主题色 |
| ⚡ 蓝色流光 | 电光蓝配色 + 能量网格 + 面板头能量线流动 + 主按钮脉冲扫光 |
| 🔥 火焰流动 | 熔金→熔岩橙→烈焰红 + 底部火舌起伏 + 飞升火星 + **点击按钮火焰向四周喷发** |

- **一键改主题色**：6 个预设圆点 + 自定义取色器。改色后**所有面板的按钮、导航、输入框、卡片、面板描边、标题色阶会同步跟随**（主题自带的动效层与背景色按主题固定）

## 14. 缓存与清理

### 时间线「🗑 清空」会自动清三类缓存

点一次「🗑 清空」= 清空分镜 + 清缓存，避免旧缓存影响后续生成：

| 清什么 | 为什么 |
|---|---|
| 面板内状态（分镜配置 / 选择 / 出片预览 / 实时预览轮询） | 切模式或重跑时不会残留上一轮的预览帧 |
| `output/mrnext_preview/*.jpg`（采样实时预览图） | 残留会让下一轮在写出首张预览前显示上一轮的旧帧 |
| `input/{folder}/_plan.json` → **归档**为 `_plan.prev.json` | 残留会让节点认为还有分镜计划，从而重跑旧计划干扰新生成 |
| `output/mrnext_thumbs/*.jpg`（素材缩略图） | 源文件变了但缓存在，会显示旧图 |

日志会回执：`🧹 缓存已清理：采样预览图 N · 素材缩略图 M · 旧计划已归档`。

### 其他需要手动清的情况

| 位置 | 何时清 |
|---|---|
| `output/mrnext_preview/` | 觉得实时预览串了别的任务 |
| `output/mrnext_thumbs/` | 缩略图与素材对不上 |
| `user/mrnext_favorites.json` | 收藏库乱了（删掉会重建） |
| 浏览器 `localStorage` 的 `mrnext.*` | 面板状态异常（也可在节点报错条上点「🧹 重置面板状态并重新加载」） |

## 15. 常见问题排查

| 症状 | 原因 | 解决 |
|---|---|---|
| 画布搜不到节点 | 包没解压完整 / 没重启 | 检查 `custom_nodes/ComfyUI_MRBoard_Next/__init__.py` 与 `vendor/` 是否存在，重启 ComfyUI |
| 面板全空白 | 浏览器缓存旧前端 | **Ctrl+F5 硬刷新**；仍空白就 F12 看 Console 里的 `MRBoardNext` 报错 |
| 版本徽章不是最新 | 同上 | Ctrl+F5；确认 `main.js` 顶部 `MRNEXT_VERSION` 与包版本一致 |
| 模型下拉是空的 | 模型放错目录 | 对照第 3 节路径表，重启一次 |
| 面板下方一大片空白 | 旧版布局问题 | v1.9.1+ 已修（编辑区撑满），升级即可 |
| 生图报 `got an unexpected keyword argument 'enhance_scale'` | v1.9.0–1.9.3 的签名 bug | 升级到 **v1.9.4+** |
| 选「VOSR2」没反应 / 提示缺失 | 节点包或模型不全 | 装 `ComfyUI-VOSR2` + `models/vosr2/` 模型后重启；面板会给出具体缺什么 |
| 文生视频画面不按提示词走 | ① CLIP 用了 4bit `nvfp4_awq` ② 旧版英文兜底稀释中文 | ① 「🧠 模型」换成 int8 版 ② 升级到 v1.7.7+ |
| 出片时预览显示的还是上一轮的图 | 旧版预览没绑定本次任务 | 升级到 v1.9.0+（预览带 `?since=` 只认本次生成的图） |
| 画面里出现奇怪 token（如 `@image#1:xx.png`） | 粘贴进了"虚拟引用" | v1.7.5+ 已在四层净化（粘贴入口 / store / 发送层 / 后端）；升级即可 |
| 人物张嘴说胡话 / 说话乱说 | 提示词缺三段式声音字段 | v1.7.6+ 已自动组装三段式；确认「🎙️ 声音」页没关掉 |
| 音轨失真 / 变噪音 | 步数 <8（ComfyUI 稳定版 bug） | 用 8 步以上，或升 nightly；护栏也会自动抬步数 |
| 想跑 4–6 步加速 | 需 nightly + 蒸馏 LoRA | 升 nightly；LoRA 强度在 0.5–1.0 扫 |
| 节点被预览大图撑高 | 旧版会给 OUTPUT_NODE 加画布预览 | v1.7.8+ 已屏蔽 |
| 长时段连跑 OOM | 显存累积 | 时间线勾「段间清理显存（每2镜）」 |
| 出片很慢 | 正常 | 864×480 / 12 步在 16G 卡上约 1–3 分钟/镜 |
| 剪辑合成报未找到 ffmpeg | 缺 `imageio_ffmpeg` | 按第 2.2 节装依赖 |
| 剪辑导入按钮点了没反应 | 系统文件选择框被拦 | 点 `▾` 用「浏览器上传」兜底 |
